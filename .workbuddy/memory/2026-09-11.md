## 打印设计器架构分析（专家 eno 模式）
- 项目现状：Vue3.5 + Vite8 + TS6 + Tailwind4 + reka-ui，三栏布局已搭好，DesignPanel 空白待实现
- 结论：选 Konva.js + vue-konva（2026 月下载 10.1M，官方 Vue 绑定，交互式编辑器首选）
- 架构：四层 = UI 层 / Pinia 状态层 / Konva 渲染层 / 数据层
- 素材模型：BaseElement 基类 + 策略模式 render(konvaNode)；文本/表格/线条(dash区分虚实)/图片
- 视口交互：缩放围绕指针、平移区分拖画布vs拖元素、网格按视口动态绘制、吸附 dragBoundFunc + Math.round(x/grid)*grid
- 分阶段路线：P0 骨架+缩放平移 → P1 网格吸附+素材模型+选中+属性台 → P2 表格图片+撤销+导出
