## 下午 12:50 修页码定位 bug（老板截图：调大下边距页码压住表格）

- 症状：下边距调大后，页码「第 1 页 / 共 32 页」叠在表格最后一行上，下方大片空白。
- 根因：footerStyle 写成 `bottom = marginMm.bottom` —— 页码底边贴着**正文区底边**、文字向上长进正文区；下边距调大 → 正文区底边上移 → 页码跟着贴上去压表格。交付时说"页脚落在下边距区域内"实际写反了。
- 修法（仅 `PreviewPage.vue`）：页码**贴纸张物理底边**（理想偏移 5mm 常量 FOOTER_BASELINE_MM），不随下边距走；几何约束 bottom + 行高 4.2 ≤ M_b，下边距小到装不下才收进条带（`max(0, min(5, M_b - 5.2))`），M_b < 5.2mm 的极端情况贴死纸底（边距本身设太小）。
- 验证：check-templates 127 零错、eslint 0、vite 200。
- 待老板手点：调大下边距 → 页码应纹丝不动贴着纸底；表格最后一行与页码不再重叠。
