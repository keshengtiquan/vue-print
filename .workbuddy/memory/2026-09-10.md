## 排查页面空白（白屏）
- 根因：`src/router/routes/index.ts` 里 `import.meta.glob('./modules/**/*.ts', { eager: true })` 在 `export const Layout` 之前执行，而 `modules/main.ts` 又 `import { Layout } from '..'`，形成循环依赖 + TDZ，运行时报 `Cannot access 'Layout' before initialization`，应用挂载失败 → 白屏
- 修复：把 `export const Layout` 提到 glob 之前
- 验证方式：用 Vite `createServer` + `ssrLoadModule('/src/router/routes/index.ts')` 确认模块可正常加载（3 条路由、1 条动态路由）；build 由 12 模块变 30 模块
- 经验：路由动态模块若从父 index 反引 Layout 常量，务必先定义再 eager glob；或改为直接 `() => import('@/layout/index.vue')` 消除循环依赖
