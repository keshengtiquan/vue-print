# 2026-09-17

## 线宽单位 mm → px（只给方案，未实施）

需求：线条属性面板里「线宽」输入显示成 px，底层存储仍是 mm。老板要求先列方案。

调研结论：
- `element-property-config.ts` 的 `PropertyFieldConfig.displayUnit`（"pt" | "px"）机制**已经存在**，
  `ElementProperties.vue` 的 `displayValue()` 负责 mm→px/pt 换算显示（px 保留 1 位小数），
  `setField()` 负责反算回 mm 写入 store。text.borderWidth、table.cellStyle.borderWidth 已用 px 口径。
- 渲染层不用改：`LineElement.vue` 本来就是 `stroke.width(mm) * pxPerMm(scale)`；
  text/table 的 borderWidth 同理。底层 mm = 物理尺寸，px 只是输入口径。
- 换算常数：1mm = 96/25.4 px ≈ 3.7795px；1px ≈ 0.2646mm。素材默认线宽 0.5mm → 面板显示 1.9px（非整数）。

发现两个既有 bug（改线宽前要顺手修）：
1. `ElementProperties.vue` `setField()` 里 `field.min` 的 clamp 用的是 `rawValue`，
   紧接着 `if (field.displayUnit === "px") value = pxToMm(Number(rawValue))` 用 rawValue 覆盖了 clamp 结果
   → **带 displayUnit 的字段 min 完全失效**（输入负数也能写进去）。
2. number 字段模板 `:model-value="Number(displayValue(field)) || field.min || 0"`，
   底层值为 0 时会被 `||` 兜底成 min，面板显示与真实值不符。

给出三个方案（推荐 A）。待老板拍板项：min/step 取值、虚线间隔 dash 是否一起转 px、
素材默认线宽是否调成整数 px（1px = 0.2646mm）。
