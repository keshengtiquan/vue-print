# 2026-09-16

## 元素锁定态：红色选框 + 属性台全禁用

需求：选中元素锁定后，画布选框变红；右侧属性台的所有属性控件禁用。

- `designPanel/components/elements/ElementWrapper.vue`：选中框颜色改为按 `element.locked` 三元互斥取色 —— 锁定走 `border-destructive`，正常仍是硬编码 `border-[#1a73e8]`。虚线样式不变。手柄/旋转柄本来就 `v-if="!element.locked"` 不渲染，这次只补颜色语义。
- `setting/element/ElementProperties.vue`：
  - 新增 `locked` computed（`element.locked ?? false`），逐个控件传 `:disabled="locked"`（NumberField / Input / Textarea / SelectTrigger / Switch / ColorPicker）。共 3 个分区 12 个控件。
  - 顶部加了一条锁定说明条（`border-destructive/30 bg-destructive/10 text-destructive`）+ 「解锁」按钮，直接调 `store.updateElement(id, { locked: false })`。原因：全禁用后面板内必须留个出口，否则用户只能去画布右键。
- `color-picker/ColorPicker.vue`：原本不支持禁用，新增可选 `disabled?: boolean` prop 透传给 `PopoverTrigger`（reka 的 PopoverTrigger **没有** disabled 逻辑，靠原生 button 的 disabled 属性拦住 click，实测可行），并补 `disabled:cursor-not-allowed disabled:opacity-50`。

验证：eslint 三个文件零报错；`npx vite` + curl 取三个 `.vue` 转换产物确认无编译错误且改动已进产物；再 curl `src/styles/index.css` 确认 `border-destructive` / `border-destructive/30` / `bg-destructive/10` 都被 Tailwind 生成（v4 按需生成，类名写错会静默失效，必须回查 CSS）。
