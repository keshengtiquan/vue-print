# 打印设计器架构分析与实现路线

> 基于 2026-09-11 最新调研，针对当前 vue-print 项目的「设计面板」阶段梳理主流实现方案。

## 一、项目现状

- 技术栈：Vue 3.5 + Vite 8 + TypeScript 6 + Tailwind CSS v4 + reka-ui（shadcn-vue 风格）
- 已具备：三栏布局骨架（素材台 Material / 设计面板 DesignPanel / 属性台 Setting）、Header 工具栏
- 缺口：DesignPanel 目前是空白占位，素材台/属性台仅标题栏

## 二、技术选型结论：Konva.js + vue-konva

打印设计器属于「交互式图形编辑器」场景。2026 年主流 Canvas 引擎对比：

| 引擎 | 月下载 | 定位 | 适配度 |
|---|---|---|---|
| **Konva.js** | 10.1M | 交互式编辑器 | ✅ 首选：场景图 + 事件冒泡 + Transformer 手柄 + 官方 Vue 绑定 |
| Fabric.js | 3.7M | 设计工具/图片编辑 | 无官方 Vue 绑定，2000+ 节点后性能吃力 |
| PixiJS | 3.8M | 2D 游戏 | WebGL 引擎，杀鸡用牛刀 |

选 Konva 核心理由：`vue-konva` 提供 `v-stage` / `v-layer` / `v-rect` / `v-text` / `v-transformer` 等声明式组件，与 Vue3 响应式无缝契合，拖拽/缩放/旋转/序列化开箱即用。

安装：
```
pnpm add konva vue-konva
```

## 三、四层架构设计

1. **UI 层**：素材台 / 设计面板 / 属性台 / Header
2. **状态层（Pinia）**：`doc`（文档）、`selection`（选中态）、`viewport`（缩放/平移）、`history`（撤销历史）
3. **渲染层（Konva Stage）**：网格层 / 元素层 / 选框层 / 比例尺层 / Transformer 层
4. **数据层**：元素模型 + JSON 序列化 + 撤销快照

核心原则：**UI 单向读 store → store 变更驱动 Konva 重绘 → 数据模型与渲染节点解耦**。

## 四、素材元素模型（统一基类 + 策略模式）

所有素材继承 `BaseElement`：

```ts
interface BaseElement {
  id: string
  type: 'text' | 'table' | 'line' | 'image' | ...
  x: number
  y: number
  width: number
  height: number
  rotation: number
  zIndex: number
}
```

- 文本 Text：content / font / color
- 表格 Table：rows / cols / cellStyle
- 线条 Line：points / stroke / dash（实线/虚线通过 dash 数组区分）
- 图片 Image：src / objectFit

每种素材实现 `render(konvaNode)` 方法（策略模式），把数据模型映射为 Konva 节点。新增素材 = 新增一个类 + 一个渲染函数。

序列化：`doc = { paper, elements[] }` → JSON；撤销靠变更前深拷贝快照入栈。

## 五、画布视口交互实现要点

### 缩放
- 滚轮 / 按钮两种触发，**以指针为锚点**缩放
- scale 范围 0.1 ~ 3
- 缩放后按指针位置反算 `stage.position`，保证不偏移

### 平移
- 拖空白区 / 空格键拖拽移动 `stage.position`
- 需区分「拖画布」vs「拖元素」（用 hit 检测或专用空白占位层）

### 网格
- 背景层动态绘制，按视口范围计算应画的横/竖线，只画可见区域
- `cellSize` 随缩放自适应，`strokeWidth = 1 / scale` 保持视觉粗细一致

### 网格吸附
- 移动吸附：`dragBoundFunc` 回调里 `Math.round(x / grid) * grid`
- 缩放吸附：`transformend` 后二次修正，或自定义 Transformer 手柄
- 公式：`Math.round(value / gridSize) * gridSize`
